# FlyLog

[English](README.md) · [Português (BR)](README.pt-BR.md)

Офлайн-журнал польотів і менеджер флоту для пілотів дронів/БПЛА. Фіксуйте польоти, керуйте флотом і акумуляторами, ведіть власні показники — все працює локально у вашому браузері, без сервера.

## Можливості

- **Журнал польотів** — записуйте польоти для кожного апарата з часом початку, часом завершення та тривалістю; заповніть будь-які два значення — третє розрахується автоматично. Будь-який збережений запис можна згодом відредагувати, якщо сталася помилка.
- **Керування флотом і акумуляторами** — дрони та акумулятори зберігаються у згортних картках (за замовчуванням згорнуті, розгорніть для повної статистики й дій), кожна з повністю власними статусами, які можна додавати, видаляти й перефарбовувати під свій робочий процес.
- **Термін служби дрона** — розгорніть картку дрона, щоб побачити дату й час першого та останнього польоту, а також термін служби між ними (наприклад, «45 хв» або «1р 3міс 25д 3г 45хв»). Панель «Термін служби флоту» на дашборді підсумовує це в мінімальний, середній і максимальний термін служби по всьому флоту (дрони без польотів не враховуються).
- **Зміна порядку техніки** — перетягуйте або використовуйте кнопки вгору/вниз, щоб розташувати дрони й акумулятори у звичному для вас порядку. Нові елементи додаються нагору, і цей самий порядок визначає списки «Апарат/Акумулятор» у формі запису польоту.
- **Власні поля** — створюйте власні поля журналу польотів для будь-яких даних, важливих для вашої роботи, кожне з власним графіком тренду на дашборді.
- **Графіки та статистика** — графік тренду льотних годин перемикається між переглядами «За тижнями» (8 тижнів), «За місяцями» (6 місяців) та «За останні 30 днів».
- **Резервні копії та експорт** — у будь-який момент завантажте повну резервну копію у форматі JSON (або відновіть/об'єднайте її), а також експортуйте журнал польотів у CSV одним натисканням. Оскільки всі дані зберігаються у браузері, періодичне створення резервної копії — це єдиний спосіб убезпечити свої дані.
- **Встановлюваний PWA** — встановіть на головний екран і користуйтеся офлайн завдяки service worker.
- **Багатомовність** — доступно англійською, українською та португальською (бразильською).
- **Зберігання лише локально** — усі дані залишаються у `localStorage` вашого браузера; нічого не надсилається на сервер.

## Використання

FlyLog — це один статичний HTML-файл без етапу збірки чи залежностей. Щоб запустити його:

1. Відкрийте `index.html` безпосередньо в браузері, або
2. Запустіть папку через будь-який статичний файловий сервер (наприклад, `npx serve .`) і відкрийте у браузері.
3. За бажанням встановіть його як PWA через запит на встановлення у браузері для офлайн-використання.

## Дані та приватність

Усі дані про польоти та флот зберігаються локально у вашому браузері через `localStorage`. Нічого не передається на жоден сервер. Очищення даних браузера видалить їх, тож регулярно експортуйте/створюйте резервні копії, якщо ці дані важливі для вас.
